OBS WebSocket 5.x

Connect to OBS Studio

How to connect
  1. Open OBS Studio.
  2. Go to Tools > WebSocket Server Settings.
  3. Enable the WebSocket server and keep port 4455.
  4. Copy the server password and enter it below.
  5. Use the exact microphone input name shown in OBS Audio Mixer.

Connecting from another device? Replace 127.0.0.1 with the OBS computer's local IP address.

▶Connect YouTube account

OAuth enables sending messages as your YouTube channel.

YouTube setup guide
  1. Open the Google Cloud project creator and create or select a project.
  2. Open the YouTube Data API v3 page and click Enable.
  3. Configure the OAuth consent screen. Add yourself as a test user while the app is in testing.
  4. Open Google credentials, create an OAuth client ID, and choose Web application.
  5. Add this authorized redirect URI:https://stream-command.vercel.app/api/oauth/youtube/callback
  6. Copy the Client ID and Client Secret into Vercel Environment Variables as YOUTUBE_CLIENT_ID and YOUTUBE_CLIENT_SECRET, then redeploy.
  7. Return here and click Connect YouTube account. Approve the requested youtube.force-ssl permission.
◈Connect Twitch account

OAuth enables sending messages as your Twitch account.

Twitch setup guide
  1. Open the Twitch application registration page.
  2. Enter a unique application name, choose Application Integration, and set Client Type to Confidential.
  3. Add this OAuth redirect URL:https://stream-command.vercel.app/api/oauth/twitch/callback
  4. Open the app's Manage page, copy its Client ID, and create a new Client Secret.
  5. Add them in Vercel Environment Variables as TWITCH_CLIENT_ID and TWITCH_CLIENT_SECRET, then redeploy.
  6. Return here and click Connect Twitch account. Approve the requested user:write:chat permission.
Facebook setup guide
  1. Open Meta app creation and create a Business app linked to your Facebook Page.
  2. Open the Graph API Explorer, select your app, and request pages_show_list, pages_read_engagement, and pages_manage_posts.
  3. Run GET /me/accounts. Copy your Page's id and Page access_token into the fields below.
  4. Open Facebook Live Producer to start a Page livestream. Leave Live Video ID empty for automatic detection.
  5. Use Access Token Debugger to verify token permissions and expiration.
  6. Facebook comments can be monitored now. Sending replies for users outside the app's roles usually requires Meta App Review.

OBS WebSocket 5.x

Connect to OBS Studio

How to connect
  1. Open OBS Studio.
  2. Go to Tools > WebSocket Server Settings.
  3. Enable the WebSocket server and keep port 4455.
  4. Copy the server password and enter it below.
  5. Use the exact microphone input name shown in OBS Audio Mixer.

Connecting from another device? Replace 127.0.0.1 with the OBS computer's local IP address.

Platform settings

Connect YouTube
  1. Open Google Cloud Console and create or select a project.
  2. Open APIs & Services > Library, search for YouTube Data API v3, and enable it.
  3. Open APIs & Services > Credentials, choose Create credentials > API key, then copy the key.
  4. Find your Channel ID in YouTube Advanced Settings.
Connect Twitch
  1. Open the Twitch Developer Console and register an application.
  2. Use http://localhost:4173 as the OAuth redirect URL and choose any suitable category.
  3. Open the application and copy its Client ID. Click New Secret to get its Client Secret.
  4. Generate an App Access Token using the command shown below, then enter your Twitch username without @.
Invoke-RestMethod -Method Post -Uri "https://id.twitch.tv/oauth2/token?client_id=CLIENT_ID&client_secret=CLIENT_SECRET&grant_type=client_credentials"
Connect Facebook
  1. Open Meta for Developers and create an app linked to your Facebook Page.
  2. Open Graph API Explorer, select your app, and generate a token with pages_read_engagement and pages_manage_posts.
  3. Request GET /me/accounts in Graph API Explorer. Copy your Page's id and Page access_token from the response.
  4. Meta may require App Review before these permissions work for users outside your app roles.
